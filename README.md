# Discover Lesotho Tourism Website

## Publish with GitHub Pages
1. Create or open the GitHub repository you want to use.
2. Upload the **contents of this folder** (not the ZIP file and not an extra `lesotho-tourism` folder).
3. Make sure `index.html` is directly in the repository's main/root directory.
4. Open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Choose branch `main` and folder `/(root)`, then click **Save**.
7. Wait for GitHub Pages to finish publishing, then open the URL shown on the Pages settings screen.

All image paths use lowercase filenames and the `images/` folder to avoid GitHub Pages case-sensitive path errors. CSS and JavaScript are in their own folders. Bootstrap is loaded from a CDN, so an internet connection is required for Bootstrap styling and interactive components.
